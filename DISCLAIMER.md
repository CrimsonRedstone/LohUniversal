# Names, trademarks, and what this software is

Лох Universal is an **original software instrument**. It implements a well-known synthesis method from the 1960s (top-octave divide-down organs) and a user interface in the visual language of that era (orange covering, reverse-colour keys, drawbars, rockers).

It is **not**:

- a Vox Continental, Vox Super Continental, or any other Vox / Korg product
- a Jennings, Univox, or Gibson combo organ
- an Arturia, Korg, or Native Instruments plugin
- a Hammond organ or a Leslie speaker
- an official replica, emulation product, or “endorsed recreation”

**Korg**, **Vox**, **Continental**, **Jennings**, **Hammond**, **Leslie**, **Arturia**, **Steinberg**, **ASIO**, and related names are trademarks of their respective owners. They are mentioned here only to say we are **not** them.

User-facing engine and amp names in the plugin are generic:

| In the plugin | What it means musically |
| --- | --- |
| Model 301 | Flute-forward divide-down combo |
| Super Combo | Brighter reed voicing |
| Saw Combo | Leaky-integrator / saw bus |
| Extended | All ranks available |
| Combo Cabinet | British 1×12 guitar-amp cabinet colour |
| Rotary Speaker | Horn + drum rotating speaker |

Do not name GitHub repositories, release titles, or store listings “Vox Continental”, “VoxConti”, or similar. The public name is **Лох Universal** / **Loh Universal**.
