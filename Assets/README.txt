Лох Universal — Assets
======================

Fonts live in Assets/Fonts/ and are compiled into the binary
(Inter + Great Vibes). See Fonts/README.txt.

The GUI is otherwise drawn in code (Rexine lid, reverse keybeds,
metal/LED drawbars, rockers, trim pots, FX stomps).

Five chassis themes: Default, Crimson, Nosmirc, Citrus Frost, Junkyard.
