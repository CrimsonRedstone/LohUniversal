# Лох Universal 1.0.0

Freeware transistor combo organ by Crimson Redstone.

## What it is

A **synthesized** 1960s-style divide-down combo organ: top-octave oscillators, binary dividers, drawbars, vibrato, percussion, effects, cabinet, and rotary speaker. VST3 / AU / CLAP / Standalone.

It is an original instrument, not affiliated with Korg, Vox, Jennings, Hammond/Suzuki, or Arturia.

## Windows install

1. Unzip.
2. Copy `LohUniversal.vst3` to `C:\Program Files\Common Files\VST3`.
3. Rescan plugins in your DAW. It is an **Instrument / Synth**.
4. Optional: run the standalone `.exe`.

macOS / Linux: build from source (`README.md`).

## In this release

- Dual-manual divide-down engine (Model 301, Super Combo, Saw Combo, Extended)
- Drawbars, flute/reed voicing, vibrato, percussion
- FX rack, combo cabinet, rotary speaker, 5-band EQ
- Five chassis skins, factory presets, `.lohpreset` save/load
- GPL-3 source — compile it yourself with CMake + JUCE 9.0.1
